# 相机存储比赛批量删除

入口：云存储 → 相机存储 →「管理」，或长按比赛。支持逐场、按日期和全选；只有明确可删除的比赛参与全选。底部显示所选场数，点击删除后再次确认。删除相机中的比赛目录（视频、缩略图和比赛资料），手机与云端已有副本保留；删除无法恢复。

执行时逐场串行发送，显示当前比赛、完成数和进度。点「停止后续删除」只停止后续任务，当前任务完成后退出。结果分别显示成功、失败、未执行及待核对数量；失败与未执行的比赛可重新确认后重试。超时、断线、切换相机或访问模式变化时暂停，不自动重放；先获取关联的完整比赛列表核对，再允许重试。旋转屏幕保留选择与进度，进程重建只恢复待核对状态。

## 本地协议

新版相机 `video_list` 回显 `request_id`，附带真实 `device_id` 和 `video_delete_protocol: 1`；比赛行附带 `delete_identity`（录制开始时间的毫秒字符串）、`delete_block_reason`。旧版列表仍可浏览，批量管理提示升级相机。

每场 `video_delete` 附带 UUID `request_id`、`path`、`expected_device_id` 和列表返回的 `expected_time`；相机核对自身身份、比赛开始时间、目录边界及忙碌状态，回复 `c/r/request_id/device_id/path`。请求 ID 用于关联回复，不是服务器授权或录制序号。单场旧协议保留，批量回复不触发旧详情页删除回调。

相机只接受视频根目录下 `YYYYMMDD/比赛目录`，拒绝路径穿越与符号链接目录。删除与录制启动/恢复使用同一个跨进程锁；录制中、启动中、有处理标记或持有处理/上传/下载读取租约的目录不可删除。删除租约也阻止新处理/上传/读取任务进入。比赛标识变化时拒绝旧请求，避免同路径新比赛被误删；已不存在的目录可幂等返回成功。

批量删除通过 App 与相机现有本地通道执行，不需服务器在线。相机身份和目录状态校验不替代现有登录、每日联网校验和录制权限机制。删除不写入离线额度、授权或用量回执，不退还录制/直播次数。本次服务端无代码变更。
